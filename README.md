# campo-minado-

Jogo clássico de Campo Minado desenvolvido em Java, com interface gráfica utilizando Swing.

## Funcionalidades

- Três níveis de dificuldade: Fácil, Médio e Difícil.
- Geração aleatória de minas.
- Proteção contra minas no primeiro clique.
- Revelação de células e identificação de minas adjacentes.
- Marcação de minas com o botão direito.
- Contador de minas.
- Cronômetro.
- Identificação de vitória e derrota.
- Reinício de partida.

## Tecnologias

- Java
- Java Swing
- Java AWT

## Download

Acesse [Releases](https://github.com/gtakii/campo-minado-/releases), baixe o arquivo `.jar` e execute com dois cliques.

**Requisito:** Java instalado e compatível com a versão utilizada na compilação. Não é necessário utilizar uma IDE.

## Executar pelo código-fonte

```bash
git clone https://github.com/gtakii/campo-minado-.git
cd campo-minado-
javac CampoMinado.java
java CampoMinado
```

## Conceitos aplicados

- Programação Orientada a Objetos.
